# 🌟 ElevateU - Learning Platform

ElevateU is a full-stack MERN (MongoDB, Express.js, React, Node.js) learning platform designed to help students and professionals navigate career paths with structured **Roadmaps**, **Courses**, and **Tracking Features**. It includes GenAI, Cybersecurity, Data Analysis, Web Dev, and more!

---

## 🚀 Features

- ✅ **User Authentication** (Register/Login)
- 🧠 **AI/ML, Cybersecurity, Web Dev, Data Analyst** Roadmaps
- 🎓 **Course Pages** with Docs + YouTube Playlist
- 📄 **Dynamic PDF Generation**
- 📈 **Track Progress** (in progress)
- 💬 **Contact Page** for Queries
- 🌐 Fully Responsive UI with Tailwind CSS + Framer Motion
- 🔐 Protected Routes (Courses accessible only after login)

---

## 🛠️ Tech Stack
